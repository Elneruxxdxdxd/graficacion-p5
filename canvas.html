La etiqueta <canvas> y el contexto 2D

El lienzo de HTML5 es la base sobre la que trabajan librerías como p5.js. Entender cómo funciona permite saber qué ocurre "debajo" de cada ellipse() o rect().

1. ¿Qué es <canvas>?

La etiqueta <canvas> se introdujo en HTML5 y define un área rectangular de píxeles dentro de la página en la que se puede dibujar mediante JavaScript. Por sí sola no dibuja nada: es solo un contenedor vacío. Todo el contenido gráfico (formas, texto, imágenes, animaciones) se genera desde un script a través de un contexto de renderizado.

A diferencia de SVG, que es un formato vectorial donde cada figura es un elemento del DOM, el canvas es un mapa de bits (raster) que trabaja en modo inmediato: una vez que se dibuja una figura, el navegador solo conserva los píxeles resultantes, no el objeto. Para "mover" algo hay que borrar y volver a dibujar la escena completa. Esto lo hace muy eficiente para animaciones, juegos y visualizaciones con muchos elementos.

<canvas id="lienzo" width="400" height="400">
  Tu navegador no soporta el elemento canvas.
</canvas>

El texto entre las etiquetas es contenido alternativo: solo se muestra en navegadores que no soportan canvas y sirve también como descripción para lectores de pantalla.

2. Atributos y tamaño

El canvas tiene dos atributos propios: width y height, que definen la resolución interna del lienzo en píxeles (300×150 por defecto). Es importante distinguirlos del tamaño visual que se asigna con CSS:

  • Atributos width/height: cuántos píxeles reales tiene el mapa de bits.
  • CSS width/height: el tamaño con que se muestra en pantalla. Si no coincide con la resolución interna, el navegador estira la imagen y se ve borrosa o deformada.

En pantallas de alta densidad (Retina) se suele multiplicar la resolución interna por window.devicePixelRatio y escalar el contexto para obtener trazos nítidos. p5.js hace esto automáticamente mediante pixelDensity().

3. Contextos de renderizado

Para dibujar se obtiene un contexto con el método getContext(). El tipo de contexto determina qué API de dibujo se usa:

const canvas = document.getElementById("lienzo");
const ctx = canvas.getContext("2d");   // contexto de renderizado 2D
ContextoObjeto que devuelveUso
"2d"CanvasRenderingContext2DGráficos 2D: formas, trazados, texto, imágenes y transformaciones. Es el que usa p5.js por defecto.
"webgl" / "webgl2"WebGLRenderingContextGráficos 3D acelerados por GPU basados en OpenGL ES. p5.js lo usa con createCanvas(w, h, WEBGL).
"webgpu"GPUCanvasContextAPI moderna de bajo nivel para GPU, sucesora de WebGL.
"bitmaprenderer"ImageBitmapRenderingContextMuestra un ImageBitmap ya generado (por ejemplo, desde un Worker).

Un canvas solo puede tener un tipo de contexto: si se pide "2d", después ya no se puede obtener "webgl" del mismo elemento. Si el contexto no está disponible, getContext() devuelve null.

4. Sistema de coordenadas

El origen (0, 0) está en la esquina superior izquierda. El eje X crece hacia la derecha y el eje Y crece hacia abajo (al contrario del plano cartesiano de matemáticas). En un lienzo de 400×400, el punto central es (200, 200) y la esquina inferior derecha es (400, 400). Los ángulos se miden en radianes y avanzan en el sentido de las manecillas del reloj.

5. Principales métodos del contexto 2D

Rectángulos

  • fillRect(x, y, ancho, alto) — rectángulo relleno.
  • strokeRect(x, y, ancho, alto) — solo el contorno.
  • clearRect(x, y, ancho, alto) — borra el área (la vuelve transparente).

Trazados (paths)

Cualquier otra figura se construye como un trazado:

ctx.beginPath();           // inicia un trazado nuevo
ctx.moveTo(160, 100);      // mueve el "lápiz" sin dibujar
ctx.lineTo(210, 30);       // línea hasta este punto
ctx.lineTo(260, 100);
ctx.closePath();           // cierra la figura
ctx.fill();                // rellena  (o ctx.stroke() para el contorno)

ctx.beginPath();
ctx.arc(330, 70, 35, 0, Math.PI * 2);  // círculo: centro, radio, ángulos
ctx.fill();

También existen quadraticCurveTo(), bezierCurveTo(), ellipse() y rect() para curvas y figuras dentro de un trazado.

Estilos

  • fillStyle y strokeStyle — color de relleno y de contorno (acepta colores CSS, degradados y patrones).
  • lineWidth, lineCap, lineJoin — grosor y forma de las líneas.
  • globalAlpha — transparencia global.
  • createLinearGradient() / createRadialGradient() — degradados.

Texto e imágenes

  • font, fillText(texto, x, y), strokeText(), measureText().
  • drawImage(imagen, x, y, ancho, alto) — dibuja imágenes, videos u otros canvas.
  • getImageData() / putImageData() — acceso directo a los píxeles.

Transformaciones

translate(), rotate() y scale() modifican el sistema de coordenadas. save() guarda el estado actual (estilos y transformaciones) en una pila y restore() lo recupera. Son el equivalente nativo de push() y pop() en p5.js.

ctx.save();
ctx.translate(200, 185);   // mueve el origen al centro de la figura
ctx.rotate(angulo);        // gira el sistema de coordenadas
ctx.fillRect(-30, -30, 60, 60);
ctx.restore();             // regresa al estado anterior

6. Animación con requestAnimationFrame

Como el canvas no recuerda las figuras, una animación consiste en repetir el ciclo borrar → actualizar → dibujar muchas veces por segundo. La forma recomendada es requestAnimationFrame(), que sincroniza el dibujo con la tasa de refresco de la pantalla (normalmente 60 fps) y se pausa cuando la pestaña no está visible:

function dibujar() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  // ... dibujar la escena ...
  angulo += 0.02;
  requestAnimationFrame(dibujar);
}
dibujar();

Esta es exactamente la idea que p5.js encapsula en su función draw().

8. Buenas prácticas

  • Definir el tamaño con los atributos width/height (o desde JavaScript), no solo con CSS.
  • Incluir contenido alternativo o un aria-label para accesibilidad, ya que el contenido del canvas no es legible por lectores de pantalla.
  • Usar save()/restore() para aislar transformaciones y estilos.
  • Animar con requestAnimationFrame() en lugar de setInterval().
  • Para escenas estáticas, dibujar una sola vez (en p5.js: noLoop()).
