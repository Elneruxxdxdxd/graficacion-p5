1. ¿Qué es p5.js?

p5.js es una librería de JavaScript libre y de código abierto para la programación creativa, creada en 2013 por Lauren Lee McCarthy y mantenida por la Processing Foundation. Es la reinterpretación para la web de Processing, el lenguaje creado en 2001 por Casey Reas y Ben Fry para enseñar programación a artistas y diseñadores.

Internamente, p5.js crea un elemento <canvas> y utiliza su contexto 2D (o WebGL). Lo que aporta es una API más sencilla: en lugar de ctx.beginPath(); ctx.arc(...); ctx.fill(); basta con escribir ellipse(x, y, w, h). Además gestiona automáticamente el bucle de animación, los eventos del ratón y el teclado, y la densidad de píxeles.

2. Cómo se incluye en una página

Se agrega la librería con una etiqueta <script> y, después, el archivo con nuestro sketch. En este sitio se usa una copia local (lib/p5.js), aunque también puede cargarse desde un CDN:

<div id="canvas-container"></div>

<script src="lib/p5.js"></script>          <!-- librería -->
<script src="js/sketches/rana.js"></script> <!-- nuestro dibujo -->

p5.js trabaja por defecto en modo global: sus funciones (ellipse, fill, mouseX…) quedan disponibles directamente en el objeto window. Por eso cada dibujo del sitio tiene su propia página.

3. Estructura de un sketch: setup() y draw()

A un programa de p5.js se le llama sketch. Se basa en dos funciones que la librería llama automáticamente:

function setup() {
  // Se ejecuta UNA vez al inicio
  let cnv = createCanvas(400, 400);   // crea el lienzo de 400×400
  cnv.parent("canvas-container");     // lo coloca dentro del div
}

function draw() {
  // Se ejecuta continuamente (~60 veces por segundo)
  background(220);
  ellipse(mouseX, mouseY, 50, 50);
}
  • setup(): configuración inicial — crear el lienzo, inicializar variables y arreglos.
  • draw(): se repite en cada fotograma; aquí se dibuja la escena.
  • createCanvas(ancho, alto): crea el elemento <canvas>; .parent(id) lo inserta en el contenedor deseado.

5. Color y estilo

  • background(r, g, b) — pinta todo el lienzo (borra lo anterior).
  • fill(r, g, b, [alfa]) — color de relleno de las siguientes figuras; noFill() lo desactiva.
  • stroke(r, g, b, [alfa]) — color del contorno; noStroke() lo desactiva.
  • strokeWeight(n) — grosor del contorno en píxeles.
  • colorMode(HSB) — cambia de RGB a tono/saturación/brillo.

Los valores RGB van de 0 a 255. Un solo número representa escala de grises (fill(255) = blanco). El cuarto parámetro, alfa, controla la transparencia (0 = invisible, 255 = opaco); se usa, por ejemplo, para el titilar de las estrellas.

6. Orden de dibujo

p5.js dibuja como un pintor sobre un lienzo: lo último que se dibuja queda encima. Por eso en “¿Qué hay de cena?” primero se pinta la mesa, después el plato y al final la comida. Además, fill() y stroke() son “estados”: afectan a todas las figuras siguientes hasta que se vuelvan a cambiar.

7. Animación

Como draw() se repite continuamente, basta con cambiar una variable en cada fotograma para producir movimiento:

let y = 0;
function draw() {
  background(150, 205, 245);   // borrar el fotograma anterior
  ellipse(200, y, 10, 10);      // copo de nieve
  y = y + 2;                    // avanza hacia abajo
  if (y > height) { y = 0; }    // vuelve a empezar
}
  • frameCount — número de fotogramas transcurridos; con sin(frameCount * 0.05) se obtiene una oscilación suave.
  • frameRate(n) — fija los fotogramas por segundo.
  • noLoop() / loop() — detiene o reanuda el bucle de draw().
  • width y height — dimensiones del lienzo.

8. Interacción

p5.js expone variables del sistema que se actualizan solas:

  • mouseX, mouseY — posición del ratón (la rana mira a la mosca, el conejo cambia sus dientes).
  • mouseIsPressed — true mientras el botón está presionado (lengua de la rana, saludo del muñeco).
  • keyIsPressed, key, keyCode — teclado.

También se pueden definir funciones de evento que p5.js llama automáticamente: mousePressed(), mouseReleased(), mouseMoved(), keyPressed(), entre otras.

9. Transformaciones

translate(x, y) mueve el origen, rotate(ángulo) gira el sistema de coordenadas y scale(s) lo amplía. Se encierran entre push() y pop() para que no afecten al resto del dibujo:

push();
translate(250, 210);   // hombro del muñeco
rotate(angulo);        // el brazo gira alrededor del hombro
line(0, 0, 70, -35);
pop();

10. Funciones matemáticas útiles

  • random(min, max) — número aleatorio (posición de los copos de nieve).
  • map(valor, a1, a2, b1, b2) — convierte un valor de un rango a otro.
  • constrain(valor, min, max) — limita un valor a un rango.
  • dist(x1, y1, x2, y2) — distancia entre dos puntos.
  • sin(), cos(), atan2() — trigonometría para oscilaciones y ángulos.
  • Constantes: PI, HALF_PI, TWO_PI.

11. De Khan Academy (ProcessingJS) a p5.js

Los retos de Khan Academy usan ProcessingJS. La mayoría de las funciones de dibujo tienen el mismo nombre en p5.js, pero hay diferencias importantes que se tuvieron que adaptar:

AspectoKhan Academy (ProcessingJS)p5.js (código web estándar)
LienzoYa existe (400×400), no hay que crearlo.Se crea con createCanvas(400, 400) dentro de setup().
Bucle de dibujovar draw = function() { ... };function draw() { ... }
Código de inicioSe escribe suelto, fuera de funciones.Va dentro de function setup() { ... }.
ÁngulosEn grados por defecto (arc(…, 0, 180)).En radianes (arc(…, 0, PI)) o usar angleMode(DEGREES).
Variablesvarlet / const (JavaScript moderno).
Imágenesimage(getImage("avatars/..."), x, y)loadImage() en preload() y luego image().
IntegraciónSimulador del sitio, no requiere archivos.Archivos HTML + CSS + JS, se publica en cualquier servidor web (GitHub Pages).

Ejemplo de la misma sonrisa en ambos entornos:

// Khan Academy
arc(200, 192, 110, 40, 0, 180);

// p5.js
arc(200, 192, 110, 40, 0, PI);
