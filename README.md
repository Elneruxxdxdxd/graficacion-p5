# Práctica de Graficación — Despliegue de gráficos con p5.js
#Manuel Garcia Montes
Sitio web que reúne los dibujos de los retos de Khan Academy adaptados a HTML, CSS, JavaScript y p5.js.

## Contenido
- `index.html` — Página principal con menú y galería
- Dibujos: `rana.html`, `dientes-conejo.html`, `cena.html`, `dia-nevado.html`, `muneco-nieve.html`, `sol-explota.html`, `nubes-separan.html`, `estrella-fugaz.html`
- Teoría: `canvas.html` (etiqueta `<canvas>` y contexto 2D) y `p5js.html` (fundamentos de p5.js)
- `css/styles.css` — estilos · `js/main.js` — menú y visor de código
- `js/sketches/` — código p5.js de cada dibujo · `lib/p5.js` — librería p5.js v1.11
